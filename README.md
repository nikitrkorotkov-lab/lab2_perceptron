# ЛР №2 — однослойная нейронная сеть (персептрон Розенблатта)

Windows Forms, .NET Framework 4.7.2, без сторонних пакетов. Откройте lab2_perceptron.slnx в Visual Studio 2022 и нажмите F5.

Датасет: папка, где каждая подпапка — класс, либо CSV (пиксели 0/1, последний столбец — класс).
Порядок: датасет -> (опц.) файл случайных весов -> вкладки «Нейрон» -> «Однослойная сеть» -> «MLP» -> «XOR».
